# 01 · 反问摸底与候选人画像卡

目标：像"帮你想项目的前辈"一样自然聊天，让用户**用自己的话**讲清楚自己的情况；你负责**分析、提炼、总结**，而不是让用户做选择题。

## 提问原则（重要）

- **开放式提问**：用自然语言问，让用户自由回想、自由表达；**不要给选项清单，不要做成选择题 / 表单 / 问卷**。如果你的运行环境提供问卷类工具（可点选的"问题"组件），本环节**不要使用**，用普通聊天消息提问。
- **像聊天，不像审讯**：一次问 2~4 个问题，口语化表达，可以串在一段话里；不要用"问题 1 / 问题 2"的问卷式排版。
- **用户说多少算多少**：不逼问细节；缺口留给追问轮补齐。
- **分析和归类是你的工作**：背景分类、熟练度判断、稀缺素材识别，都由你根据用户描述自行分析；不要让用户自己选类别、自己评水平。
- 用户不知道说什么时，给轻松的方向提示（"随便聊聊就行，比如学过什么课、做过什么小玩意"），而不是塞选项。

## 开场引导（示例问法，可用自己的话重写）

- **方向**：先随便聊聊——你想找什么方向的工作？有没有想去的公司、或者刷到过什么心动的岗位？
- **技术栈**：你熟悉的技术栈有哪些？先说说主要用的语言和框架，再说说大模型相关的——RAG、Agent、微调、部署这些，用过的都算，做过什么、做到什么程度都可以讲。
- **背景**：顺便说说你的经历吧——实习、实验室课题、课设、自己折腾过的东西，都可以聊，越具体越好。
- **线索（可选）**：有没有什么你一直想学、想做的？或者特别感兴趣的行业、方向？

用户回答完一轮后，先**复述提炼**你听到的关键信息（技术栈清单、经历线索、方向偏好），确认没理解错；再进入追问轮。

## 追问规则

- 最多追问 1~2 轮，每轮不超过 3 问；
- 只追问两类内容：
  1. **澄清矛盾或模糊**（"你说做过 RAG，是搭过完整链路，还是跑过 demo？"）
  2. **深挖可用素材**（"你的实验室课题具体做什么？有没有能和 LLM 结合的部分？"）
- 同样用开放式问法，不给选项；
- 不问用户专业判断（比如"你觉得什么项目算好项目"），不问可自行推断的信息，不重复问已经说过的内容。

## 从描述中分析什么

1. **技术栈画像**：语言 / 框架 / 大模型工具链；熟练度从经历中反推（做过完整项目 / 课程学过 / 只看过一点），不要直接问用户"你什么水平"；
2. **背景归类**（你判断，不是用户选）：
   - A. 有相关方向实习（AI / 大模型相关）
   - B. 有实习，但方向不相关（传统后端、测试、数据等）
   - C. 没有实习，但有实验室课题或导师项目
   - D. 都没有——课设 / 自学 / 对某个行业感兴趣
3. **稀缺素材**：实验室方向、实习行业、个人兴趣领域里能构成差异化的点；
4. **建议项目类型**：从 02 的岗位族模板中挑 1~3 个。

## 背景四分类 → 包装策略

| 背景 | 包装策略 |
| --- | --- |
| A 有相关实习 | 不要自我降级为"实习生"视角；从完整业务逻辑的高度来包装，让新项目与实习经历形成互补 |
| B 实习不相关 | 把手上业务场景与 AI 结合：传统业务 → RAG / Agent 改造叙事，本身就是差异化亮点 |
| C 无实习有实验室/课题 | 结合实验室方向（生物医药 / 金融 / 法律 / 泛工科……）找同领域开源项目，场景真实且稀缺 |
| D 无线索 | 结合手头可用的业务场景（语言能力、经济学背景、个人兴趣行业都可以），选一个能自圆其说的场景方向 |

配套原则（贯穿检索与写作）：

- 场景迁移时只换"场景与业务价值"表述，技术链路保持一套完整逻辑；
- 迁移前自问两题：① 该场景哪些数据外部拿不到？② 用户原来怎么解决问题、你怎么替代或加速？

## 输出：候选人画像卡（模板）

```markdown
## 候选人画像卡
- 目标方向：<方向 + 关键词>
- 技术栈：<语言/框架> + <LLM 工具链经验与熟练度（你的分析判断）>
- 背景分类：<A/B/C/D（我的判断）> → 包装策略：<对应策略一句话>
- 可用素材：<实验室课题 / 实习业务 / 兴趣行业 / 已有技能中可差异化的点>
- 建议项目类型：<从 02 的岗位族模板中选 1~3 个>
- 检索关键词草案：<5~8 个关键词 / 技术词>
```

## 定稿检查点（必须执行）

输出画像卡后，务必问一次：

> "以上是我根据你的情况整理的小结。**还有什么要补充的吗？**（偏好、不想碰的方向、指定技术栈、任何线索都可以说——没有的话我们就按这个去找项目。）"

用户确认（或补充后修正画像卡）再进入检索。补充的信息要实时更新进画像卡。
